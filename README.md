## 🏗️ Нагрузочное тестирование лендинга «Стройматериалы»

Пет-проект по нагрузочному тестированию собственного лендинга интернет-магазина
строительных материалов с использованием **Apache JMeter** и локального
веб-сервера **Live Server (VS Code)**.

## 🎯 Цель проекта

Определить предельную нагрузку, при которой лендинг сохраняет корректную
работоспособность, и выявить точку деградации системы.

## 🛠️ Стек и инструменты

| Инструмент | Назначение |
|---|---|
| Visual Studio Code + Live Server | Локальный веб-сервер (порт 5500) |
| Apache JMeter 5.6.3 | Генерация нагрузки и сбор метрик |
| HTML / CSS | Тестовый лендинг |

## 📋 План тестирования

1. Развернуть лендинг локально через Live Server.
2. Настроить JMeter: Thread Group, HTTP Request, View Results Tree, Summary Report, Graph Results.
3. Провести два сценария:
   - **Тест №1:** 500 виртуальных пользователей.
   - **Тест №2:** 1500 виртуальных пользователей.
4. Сравнить метрики (Error %, Average, Throughput) и построить графики.

## ⚙️ Конфигурация JMeter

- **Thread Group:** Ramp-up = 1 сек, Loop Count = 1
- **HTTP Request:**
  - Protocol: `http`
  - Server Name: `127.0.0.1`
  - Port: `5500`
  - Path: `/index.html`
  - Method: `GET`
- **Listeners:** View Results Tree, Summary Report, Graph Results

✅ Все 500 пользователей успешно открыли страницу — сайт стабильно

| Метрика | Значение |
|---|---|
| Samples | 1500 |

## 📈 Выводы

- Лендинг стабильно работает при нагрузке **до ~500 пользователей**.
- Точка деградации наступает **до 1500 одновременных пользователей**.
- Рекомендуемый безопасный порог — **не более 2000–3000 пользователей**
  при условии оптимизации (кэширование, CDN, статический хостинг).
